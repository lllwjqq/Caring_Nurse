# 贴心小护士 · 多智能体慢病管理平台 — 答辩 PPT 大纲

> 每页含：**标题 / 版面内容 / 视觉建议 / 口播要点**

## 页 1 · 封面

- **标题**：贴心小护士 —— 多智能体个性化慢病管理平台
- **副标题**：面向多慢病患者的 LangGraph 多智能体 · RAG 知识增强 · 语音交互
- **落款**：团队名称 / 成员 / 日期
- **视觉**：产品 Logo + 深色底渐变，主色（蓝/青）点缀
- **口播**：「大家好，我们做的是面向多慢病患者的居家慢病管理平台——贴心小护士。」

---

## 页 2 · 问题与痛点

- **标题**：慢病管理，为何这么难？
- **要点（三列图示）**：
  1. **患者基数大**：慢病人群庞大，多病共存普遍
  2. **管理碎片化**：测了没人看、建议千篇一律、随访靠自觉
  3. **老人用不了**：App 复杂、打字困难，数字化门槛高
- **视觉**：三个痛点卡片 + 数据支撑（可引慢病患病率数据）
- **口播**：「痛点可归纳为三点：管不住、不个性、老人不会用。」

---

## 页 3 · 产品定位

- **标题**：我们要做什么
- **一句话定位**：一个「会听、会说、能思考」的居家慢病管理智能体
- **三大能力**：
  - 多智能体协作（不止一个 AI，而是一支 AI 团队）
  - 个性化方案（结合档案 + 指南 + 实时指标）
  - 语音交互（老人按住说话即可，无需打字）
- **视觉**：产品一句话 + 三能力图标
- **口播**：点明「会听会说能思考」三个关键词。

---

## 页 4 · 系统架构

- **标题**：系统架构
- **要点**：分层架构图（客户端 → API 网关 → 多智能体引擎 → 数据层）
- **视觉**：放架构图（可用 .cursor/plans 里的 mermaid 流程图重绘）
  - 前端 React（8 大页面）
  - FastAPI 网关（REST + WebSocket）
  - LangGraph Orchestrator + 6 Agent
  - PostgreSQL(pgvector) + Redis + MinIO
- **口播**：「前后端分离，多智能体引擎通过 LangGraph 编排，数据层用 PG+pgvector 一库搞定向量检索，降低运维复杂度。」

---

## 页 5 · 核心技术一：多智能体协同（重点页）

- **标题**：一支 AI 团队，各司其职
- **要点**：6 Agent 角色表
  | Agent | 职责 |
  |-------|------|
  | 路由 Router | 意图识别、任务分发 |
  | 问诊 Consult | 症状咨询（RAG 引用指南） |
  | 监测 Monitor | 指标趋势分析、异常标记 |
  | 方案 Planner | 生成个性化管理方案 |
  | 随访 FollowUp | 定期随访、依从性评估 |
  | 预警 Warning | 风险分级、干预建议 |
- **视觉**：Agent 协作状态图（LangGraph 状态流转），标注「路由 → 问诊 → 方案」联动
- **口播**：「普通 chatbot 是一个大模型硬扛，我们把它拆成六个专职 Agent，由路由 Agent 统一调度，各司其职、可追溯。」

---

## 页 6 · 核心技术二：RAG 知识增强

- **标题**：回答有据可依，不是拍脑袋
- **要点**：
  - 知识来源：中国慢病防治指南（2 型糖尿病 / 高血压 / 血脂 / 慢阻肺）
  - pgvector 向量检索 → 注入 Prompt → 回答附来源引用
  - 无 API Key 时内置 Mock 降级，保证演示稳定
- **视觉**：检索流程（切片 → 向量化 → 相似度检索 → 增强生成）
- **口播**：「我们用 RAG 而非微调：两周内拿到专业输出，且每条回答都引用指南，降低大模型幻觉。」

---

## 页 7 · 核心技术三：语音交互（本期亮点）

- **标题**：按住说话，老人也能用
- **要点**：
  - **STT 听写**：长按录音 → 讯飞 IAT 转写 → 自动问诊
  - **TTS 播报**：AI 回复一键「播放语音」
  - 全链路：浏览器 16kHz 采集 → WAV → 后端提 PCM → 签名 WebSocket 调用
  - 凭证未配置时自动降级为文字输入
- **视觉**：录音按钮动效 + 语音流程箭头图
- **口播**：「这是为老年患者做的关键优化——不需要会打字，按住说话、点开就听。」

---

## 页 8 · 核心技术四：实时预警

- **标题**：异常早发现，预警秒级到
- **要点**：
  - 规则引擎（阈值表）+ ML 模型（Isolation Forest 时序异常）双引擎
  - 四级预警：绿 / 黄 / 橙 / 红，分级干预文案
  - Redis Stream + WebSocket 实时推送到前端
- **视觉**：预警分级色卡 + 实时推送动图
- **口播**：「录入超标指标，系统秒级推送预警，并根据风险等级给出就医建议。」

---

## 页 15 · 创新点总结

- **标题**：我们的创新点
- **要点（编号列出）**：
