# 输入输出规格（Input / Output Spec）

> 定位：面向老年慢病患者的 AI 输入接入与输出呈现规格，供 agent 设计与编码参考。
> 边界：本文只定义「输入怎么接、输出必须包含什么」，不规定具体 agent 划分与代码实现。

## 一、设计原则

1. 输入侧：能听别让看、能一键别多步、能选别让打字、不确定就追问。
2. 输出侧：先结论、少术语、分层次、给行动、能听（TTS）。
3. 安全红线：AI 不确诊、不自行建议改药、不省略危险信号。

## 二、输入规格

### 2.1 输入分类

| 输入类型 | 例子 | 处理通道 | 主要风险 |
|---|---|---|---|
| 报指标 | 「今天血压 140/90」 | 抽取 → 确认 → 入库 | ASR 数字错 |
| 报用药 | 「吃了片阿司匹林」 | 抽取 → 确认 → 建记录 | 药名/剂量错 |
| 描述症状 | 「这两天头晕、腿没劲」 | 问诊 / 诊断 | 表达模糊 |
| 问知识 | 「糖尿病能吃西瓜吗」 | RAG 检索 | 编造 |
| 问自己数据 | 「我最近血糖咋样」 | 查库 + 白话解读 | — |
| 请求操作 | 「帮我设个吃药的闹钟」 | 指令执行 | 误操作 |
| 上传文书 | 病历、出院小结、化验单、处方 | OCR → 抽取 → 解释 | 术语多 |
| 拍药盒 | 药盒/药瓶照片 | 识别药品 → 怎么吃 | — |
| 情绪求助 | 「我有点怕」「不舒服」 | 安抚 + 引导 | 遗漏危险信号 |
| 无效/闲聊 | 「嗯」「在吗」 | 轻量回应 | — |

### 2.2 处理规则

- 数字、药名、日期：抽取后**必须二次确认**（语音播报 + 屏幕文字同步）。
- 意图模糊（如「心口疼」）：**先追问、不猜**；追问话术要短、给选项。
- 危险信号：**立即进入红旗流程，中止其他流程**。
- 无效/闲聊：轻量回应，不追问。
- 长文/文书：进入「文书解释」流程（见第四节）。

## 三、输出规格

### 3.1 通用骨架（所有 AI 回复遵守）

1. **结论**：一句话，≤20 字，说清「是什么 / 怎么样」。
2. **关键信息**：≤3 条，口语化，数字带「偏高 / 正常 / 偏低」。
3. **行动项**：我现在该做什么（1~2 件具体事）。
4. **边界**：什么情况要就医 + 免责声明。
5. **语音版**：去掉符号、数字口语化的 TTS 文本。

### 3.2 分场景模板（示例）

- **报指标**：「您这次空腹血糖 6.8，略高于目标，建议明早再测一次。」
  （确认话术：「识别到空腹血糖 6.8，对吗？」）
- **报用药**：「已记下您吃了阿司匹林，今天的药就齐了。」
- **症状问诊**：「头晕可能和血压波动有关，建议先测一下血压。」
- **知识问答**：「糖尿病可以少量吃西瓜，但要饭后吃、控制量。」（附来源）
- **查自己数据**：「您这周血糖整体偏稳，只有周三那一次偏高。」
- **危险信号**：「这可能是紧急情况，请立即拨打 120 或马上就医。」（放第一句）

### 3.3 语音版改写规则

- 去掉括号、箭头、方括号、单位符号；
- 数字口语化：「140/90」→ 读作「一百四比九十」；「6.8」→「六点八」；
- 避免英文缩写；
- 句子之间留停顿；
- 先播「结论 + 最重要的一件事」，后续可说「接着说」展开。

### 3.4 呈现规则

- 首屏 ≤ 3 屏，细节可展开；
- 术语默认折叠，主视图用大白话，原文放「展开看原文」。

## 四、病历 / 出院小结解释规格（重点）

上传含大量专有名词的病历、出院小结，**不能整段复述，也不能只给一句摘要**，固定输出以下模块（每块大白话标题）：

| 模块 | 内容 |
|---|---|
| ① 这次是什么病 | 诊断翻成日常说法 |
| ② 现在情况 | 好转 / 稳定 / 需注意 |
| ③ 最需要注意的异常 | 挑 1~2 个最关键的，标严重度 |
| ④ 要吃的药 | 药名、怎么吃、注意什么 |
| ⑤ 生活注意 | 饮食 / 运动 / 禁忌 |
| ⑥ 何时复查 | 时间 + 科室（可一键建提醒） |
| ⑦ 出现这些情况马上就医 | 危险信号清单 |
| ⑧ 建议问医生的问题 | 帮老人列出复诊该问什么 |

补充要求：

- 术语默认折叠，原文可展开；
- 首屏只放 1~3 屏；
- 语音版先播「结论 + 最重要一件事」，细节可续播。

示例（出院小结）：

1. 您这次是因为脑血管有点堵住院的，现在已经稳定出院。
2. 血压偏低（99/63），起身要慢。
3. 阿司匹林 100mg 每天一次；瑞舒伐他汀 5mg 每晚一次。
4. 少吃盐，别摔跤。
5. 一周后去神经内科复查。
6. 突然说话不清、手脚没力，马上打 120。
7. 复诊可问：这个药要吃多久？血压低了要不要减药？

## 五、与业务模块的联动

- 用药信息 → 同步到「用药」页 / 提醒；
- 复查时间 → 可生成复诊提醒；
- 危险信号 → 触发红旗流程（120 / 立即就医）；
- 异常指标 → 进入「监测」页并可能触发预警。

## 六、验收清单（判断输出是否合格）

- [ ] 老人能否一句话听懂结论；
- [ ] 是否包含明确行动项；
- [ ] 若涉及危险信号，是否放在最前且未省略；
- [ ] 是否提供语音版；
- [ ] 术语是否已折叠、主视图是否大白话；
- [ ] 是否守住红线（不确诊、不改药、不省略危险信号）。
